# Animated media support in README / package pages

Which animated formats survive each platform's Markdown sanitizer, and the exact
syntax that works there.

## Support matrix

| Format            | GitHub README                                                                                                                                                           | GitHub issue / PR / discussion                                                                      | pi.dev packages                                             | npmjs.com                                                                        | PyPI                                                     | crates.io                                                        |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- | -------------------------------------------------------------------------------- | -------------------------------------------------------- | ---------------------------------------------------------------- |
| **GIF**           | ✅ `![](x.gif)`<br>✅ `<img src="x.gif">`<br>relative or any host                                                                                                       | ✅ `![](https://github.com/user-attachments/assets/…)`<br>✅ `<img src="…">`<br>drag-drop to upload | ✅ `![](x.gif)`<br>❌ `<img>` stripped                      | ✅ `![](https://…/x.gif)`<br>✅ `<img src="https://…">`<br>absolute URL required | ✅ `![](https://…/x.gif)`<br>✅ `<img src="https://…">`  | ✅ `![](x.gif)`<br>✅ `<img src="x.gif">`<br>relative → repo raw |
| **Animated SVG**  | ✅ `![](x.svg)`<br>✅ `<img src="x.svg">`<br>CSS/SMIL run, `<script>` stripped                                                                                          | ✅ `![](https://github.com/user-attachments/assets/…)`<br>drag-drop to upload                       | ⚠️ `![](x.svg)` presumed, untested<br>❌ `<img>` stripped | ✅ `![](https://…/x.svg)`<br>✅ `<img src="https://…">`                          | ⚠️ `![](https://…/x.svg)` camo-dependent, untested     | ✅ `![](x.svg)`<br>relative → repo raw + `?sanitize=true`        |
| **MP4 / WebM**    | ⚠️ `<video src="https://github.com/user-attachments/assets/…">`<br>❌ any other host stripped<br>❌ `![]()` never works<br>`autoplay`/`loop` stripped → click to play | ✅ bare URL on its own line<br>✅ `<video src="…">`<br>drag-drop to upload                          | ❌ nothing works                                            | ❌ nothing works                                                                 | ❌ `video` not in allowlist                              | ❌ `video` not in allowlist                                      |
| **Animated WebP** | ✅ `![](x.webp)`<br>✅ `<img src="x.webp">`<br>autoplays like a GIF                                                                                                     | ✅ `![](https://github.com/user-attachments/assets/…)`<br>drag-drop to upload                       | ✅ `![](x.webp)`<br>❌ `<img>` stripped                     | ✅ `![](https://…/x.webp)`<br>✅ `<img src="https://…">`                         | ✅ `![](https://…/x.webp)`<br>✅ `<img src="https://…">` | ✅ `![](x.webp)`<br>✅ `<img src="x.webp">`                      |

**Legend:** ✅ works · ⚠️ conditional or unverified · ❌ stripped by the sanitizer
